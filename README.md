# rdm-KULeuvenRDR-scripts
A collection of publicly available scripts for users of [KU Leuven RDR](https://rdr.kuleuven.be), the institutional research data repository of KU Leuven.
The repository is based on [the Dataverse project software](https://guides.dataverse.org/en/latest/).

This README provides an overview of all scripts in this repository with brief descriptions on scope and usage.

## Structure of the repository
Each script gets its own folder in this repository. In this folder, all accompanying files/examples/detailed documentation are stored.

## DownloadDataset
* **Purpose:** This python script helps you download a specified version of a dataset from KU Leuven RDR, keeping the directory structure. 
* **Results/Output:** The dataset downloaded into a local folder with the file structure in RDR, except for the restricted files.
* **Documentation:** [DownloadDataset/read_me.md](DownloadDataset/read_me.md)
* **License:** [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
* **Run when:** You want to download all files of a dataset from RDR, preserving its folder structure. 
* **Run where:**  On your computer locally.
